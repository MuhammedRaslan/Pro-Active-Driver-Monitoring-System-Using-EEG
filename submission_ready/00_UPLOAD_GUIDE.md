# IEEE Sensors Journal — upload guide

Open this beside the browser. Everything referenced here is in this folder.

**Portal:** IEEE Author Portal — `https://ieee.atyponrex.com/journal/sensors`
**Article type:** Regular Paper · **ORCID:** compulsory for the submitting author
**Built from:** `submission_compact/` — the only live source tree.

Last verified against a real run: **2026-08-06**.

Total upload is about **8.4 MB**. The Portal's per-submission cap is 40 MB.

**If the figure uploader rejects a PDF** — it should not, PDF is on IEEE's
accepted list — a PNG twin of every figure sits beside it on the same filename
stem, at 314–394 dpi. Use those instead. Do not mix: upload five PDFs or five
PNGs, not some of each.

## Rebuilding, if the manuscript changes

There is no system LaTeX here; the toolchain is Tectonic 0.17.0 at
`%LOCALAPPDATA%\tectonic\tectonic.exe`. From the repository root:

```bash
python submission_ready/preflight_ieee.py     --source submission_compact
python submission_ready/check_clean_render.py --source submission_compact
python submission_ready/build_package.py      --source submission_compact
python submission_ready/build_manuscript.py   --source submission_compact
```

`build_manuscript.py` writes `main.pdf` and `main_source.zip` from **one**
compile, because the Portal requires them to match. Never build them separately.

Figures are regenerated by their own scripts, each of which writes its final
`fig1_`…`fig5_` name — both `.pdf` and `.png` — straight into
`submission_compact/figures/`. There is no copy-and-rename step:

| Printed as | Generator |
|---|---|
| Fig. 1, Fig. 2 | `reviewer_revision_analysis.py` |
| Fig. 3 | `v17_roc.py` |
| Fig. 4 | `v20_lead_vs_severity.py` |
| Fig. 5 | `submission_compact/build/live_demo_sidebyside.py` |

These recompute results as a side effect. **If any number one of them prints
changes, something broke** — the figure format is not supposed to affect the
statistics. All three result JSONs were diffed after the 2026-08-06 vector
conversion and were identical apart from their timestamps.

## Specs these files were built against

| Item | Requirement | This package |
|---|---|---|
| Page limit | 8 pages double-column; **$175/page** beyond | **11 pages, $525 — accepted, see below** |
| Figure format | PS, EPS, PDF, PNG, TIF | PDF (vector) in the manuscript, PNG twins for the upload slots |
| Figure resolution | > 300 dpi colour, > 600 dpi line art | vector, so not applicable; PNG twins are 314–394 dpi |
| Figure fonts | Type 3 is a production reject | all Type0/TrueType, embedded, checked per figure |
| Figure width | 3.5 in single column, 7.16 in double | authored 3.45 in ×4 (1.01× on placement), 9.00 in ×1 (0.80×) |
| Figure colour mode | no alpha channel | PNG twins flattened to RGB |
| Graphical abstract | 672 × 456 px — a **specification** | exactly 672 × 456 |
| Graphical abstract file size | < 45 kB — IEEE's word is *recommended* | 35.2 kB |
| Graphical abstract filename | must be `gagraphic` | `gagraphic.png`, 256-colour palette, no alpha |
| Graphical abstract caption | ≤ 30 words | 26 words |
| Supplementary README | PDF or TXT, not Markdown | `README.txt`, all seven sections |
| Multimedia | MP4/MOV/WMV/AVI ≤ 100 MB, or GIF as an image | `demo_v20.gif`, 6.9 MB |
| Abstract length | 150–250 words | 235 |
| Filenames | no spaces | underscores throughout |
| Upload cap | 40 MB per submission | 8.4 MB |

### On the page count — measured, then decided

**11 pages, $525 at acceptance. This was chosen on 2026-08-06, not overlooked.**

The 8-page figure is IEEE's charging threshold, not a submission cap. Reaching
it was tested by compiling every candidate cut rather than estimating:

| Cut | Printed pages | Overlength |
|---|---|---|
| nothing (current) | 11 | $525 |
| Tables III + VI + IX | **11** | $525 |
| + Table IV | 11 | $525 |
| + Table VII (five tables gone) | 10 | $350 |
| all ten tables | 10 | $350 |
| all ten tables + one figure | 9 | $175 |
| **all fifteen floats** | **9** | $175 |
| all fifteen floats + the Limitations subsection | 8 | $0 |

The three tables that are genuinely redundant — III duplicates Fig. 1, IX
duplicates Fig. 4, VI is textbook supplementary material — are worth **zero
printed pages** between them. Deleting every figure and every table in the paper
still leaves 9. Only removing all floats *and* a discussion subsection reaches
8, which is not a paper any more.

So the length is prose-bound, not float-bound: 5,562 words of body text plus a
36-entry bibliography is 9 pages before a single float is placed.
`build_manuscript.py` now fails if the manuscript grows **past 11**, which is
the failure mode that can still happen by accident.

## At acceptance, not now

- IEEE Copyright Form (eCF) — completed in-portal after acceptance.
- Overlength page charges, **$525** (3 pages × $175).
- Open access is optional: US$2,800, with a 5 % IEEE-member / 20 % society
  discount. Traditional publication costs nothing.
